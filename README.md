🌐 **Live Demo:** [https://abduvoitov11.github.io/portfolio/](https://abduvoitov11.github.io/portfolio/)

## 🌟 Key Features

- **macOS Sonoma Lock Screen:** Live clock, date, status icons, and authentic swipe/click unlock animation.
- **Interactive Multi-Window Desktop:** Draggable, responsive modals replicating native macOS windows.
- **macOS Dock:** Interactive icons with tooltip indicators, bouncy micro-animations, and quick access.
- **Spotlight Search & Control Center:** Dynamic global search bar and macOS Control Center panel with toggleable utilities.
- **Integrated Music Player:** Vinyl album artwork animation and continuous playback controls.
- **Dynamic Wallpaper Engine:** Multiple macOS default wallpapers (Sonoma, Batman, Abstract, etc.) with custom upload capability.
- **Mobile Responsive:** Adaptive iOS-style launcher layout on mobile devices.
